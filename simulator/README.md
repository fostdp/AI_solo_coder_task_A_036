# 传感器模拟器

## 功能说明

模拟100台风力发电机组的叶片传感器数据上报系统。每台风机有3个叶片（A、B、C），每个叶片安装：
- 20个光纤应变传感器（S01-S20）
- 10个声发射传感器（AE01-AE10）

## 运行方式

```bash
pip install -r requirements.txt

# 确保后端服务已启动，然后运行：
python sensor_simulator.py
```

## 配置参数

在 `sensor_simulator.py` 中修改 CONFIG 字典：

```python
CONFIG = {
    "api_url": "http://localhost:8000/api/v1/sensor",    # 后端API地址
    "turbine_count": 100,                                 # 风机数量
    "blades_per_turbine": 3,                              # 每台风机叶片数
    "strain_sensors_per_blade": 20,                       # 每叶片应变传感器数
    "ae_sensors_per_blade": 10,                           # 每叶片声发射传感器数
    "report_interval": 600,                               # 上报间隔（秒）
    "damage_probability": 0.15,                           # 损伤发生概率
}
```

## 数据生成逻辑

### 应变数据
- 沿叶片长度方向，应变值随位置变化（根部小，尖部大）
- 叠加正弦波动模拟风机旋转效应
- 根据叶片健康度调整基线值（损伤越大应变越大）
- 加入随机噪声模拟真实传感器特性

### 声发射事件
- 健康叶片：低幅值（60-80dB）、短持续时间、低频
- 损伤叶片：高幅值（85-105dB）、长持续时间、特征频率
- 不同损伤类型有不同的频率特征：
  - 基体开裂：180-250 kHz
  - 纤维断裂：250-350 kHz
  - 分层：80-150 kHz

### 损伤特征
- 根据叶片健康度计算各类损伤概率
- 计算固有频率偏移
- 计算分层扩展速率
- 生成健康度评分
